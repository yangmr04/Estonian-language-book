# Pronouns

[Index](../README.md) · Reference · Related: [Lesson 1](../lessons/lesson-01.md), [Lesson 8](../lessons/lesson-08.md), [Lesson 32](../lessons/lesson-32.md)

Where two forms are shown, the long form comes first and the short everyday form second.

## Personal pronouns, singular

| Case | I | you | he, she |
|---|---|---|---|
| Nominative | *mina, ma* | *sina, sa* | *tema, ta* |
| Genitive | *minu, mu* | *sinu, su* | *tema, ta* |
| Partitive | *mind* | *sind* | *teda* |
| Illative | *minusse, musse* | *sinusse, susse* | *temasse, tasse* |
| Inessive | *minus, mus* | *sinus, sus* | *temas, tas* |
| Elative | *minust, must* | *sinust, sust* | *temast, tast* |
| Allative | *minule, mulle* | *sinule, sulle* | *temale, talle* |
| Adessive | *minul, mul* | *sinul, sul* | *temal, tal* |
| Ablative | *minult, mult* | *sinult, sult* | *temalt, talt* |
| Translative | *minuks* | *sinuks* | *temaks* |
| Terminative | *minuni* | *sinuni* | *temani* |
| Essive | *minuna* | *sinuna* | *temana* |
| Abessive | *minuta* | *sinuta* | *temata* |
| Comitative | *minuga, muga* | *sinuga, suga* | *temaga, taga* |

## Reflexive and possessive

| Case | *ise* "self" |
|---|---|
| Nominative | *ise* |
| Genitive | *enda, enese* |
| Partitive | *ennast, end* |
| Illative | *endasse* |
| Inessive | *endas* |
| Elative | *endast* |
| Allative | *endale* |
| Adessive | *endal* |
| Ablative | *endalt* |

*Oma* "one's own" refers back to the subject and usually doesn't change: *Ma võtan oma koti.* "I take my bag."
