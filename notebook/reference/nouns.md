# Noun Patterns

[Index](../README.md) · Reference · Related: [Lesson 7](../lessons/lesson-07.md), [Lesson 27](../lessons/lesson-27.md), [Lesson 29](../lessons/lesson-29.md), [Lesson 31](../lessons/lesson-31.md)

Estonian nouns and adjectives have three key forms: nominative, genitive and partitive. Some word shapes predict them well. Others have to be learned, so note all three when you meet a new word.

## Reliable word shapes

| Shape | Nominative | Genitive | Partitive | Meaning |
|---|---|---|---|---|
| *-ne* | *punane* | *punase* | *punast* | red |
| | *inimene* | *inimese* | *inimest* | person |
| | *naine* | *naise* | *naist* | woman |
| *-mine* | *lugemine* | *lugemise* | *lugemist* | reading |
| *-us* (abstract) | *küsimus* | *küsimuse* | *küsimust* | question |
| *-ja* (person) | *õpetaja* | *õpetaja* | *õpetajat* | teacher |
| *-ik* | *õpik* | *õpiku* | *õpikut* | textbook |
| *-lik* | *sõbralik* | *sõbraliku* | *sõbralikku* | friendly |
| *-e* (with *-da*) | *hele* | *heleda* | *heledat* | bright |
| | *tore* | *toreda* | *toredat* | great |

## From the singular to the plural

| Plural form | Built from | Example |
|---|---|---|
| Nominative | genitive singular + *-d* | *linna* → *linnad* |
| Genitive | partitive singular + *-de* or *-te* | *linna* → *linnade*, *õpikut* → *õpikute* |
| Other cases | genitive plural + ending | *linnade* → *linnades* |
| Partitive | varies by word | *linnu*, *õpikuid*, *autosid* |
