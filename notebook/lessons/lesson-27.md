# Lesson 27: The Partitive Singular

[Index](../README.md) · Book: p. 173 · § 194–214 · [← Previous](lesson-26.md) · [Next →](lesson-28.md)

## Key ideas

- The partitive answers *keda?* and *mida?* and presents something as a part or an unbounded amount.
- It ends in *-d*, *-t* or a vowel, and must be learned with the nominative and genitive.
- It appears after numbers, after quantity words, for partial objects and subjects, and with some prepositions.

## What the partitive means (§ 194–195)

*tass teed* "a cup of tea", *tükk kooki* "a piece of cake", *pudel veini* "a bottle of wine".

Word lists now give three forms: nominative, genitive, partitive. It is also the stem of most plural cases (Lesson 30).

## Partitive in -d (§ 196–199)

| Pattern | Examples |
|---|---|
| Long vowel or diphthong: add *-d* | *puu → puud, kuu → kuud, suu → suud, täi → täid* |
| Exceptions with no ending | *au, nõu* |
| Five words dropping *-i*, *-e* | *meri → merd, veri → verd, tuli → tuld, uni → und, lumi → lund* |

Pronouns:

| Nominative | Partitive | | Nominative | Partitive |
|---|---|---|---|---|
| *mina* | *mind* |  | *meie* | *meid* |
| *sina* | *sind* |  | *teie* | *teid* |
| *tema* | *teda* |  | *nemad* | *neid* |
| *kes* | *keda* |  | *see* | *seda* |
| *mis* | *mida* |  | *mõni* | *mõnd / mõnda* |

*Mis* and *mida* are often interchangeable as objects: *Mis / Mida sa ostad?* "What are you buying?"

## Partitive in -t (§ 200–203)

| Pattern | Nominative | Genitive | Partitive |
|---|---|---|---|
| Add *-t* to the genitive | *õpik* | *õpiku* | *õpikut* |
|  | *arvuti* | *arvuti* | *arvutit* |
|  | *hele* | *heleda* | *heledat* |
| Drop genitive *-e*, add *-t* | *punane* | *punase* | *punast* |
|  | *hobune* | *hobuse* | *hobust* |
|  | *uus* | *uue* | *uut* |
| Add *-t* to the nominative | *tuul* | *tuule* | *tuult* |
|  | *hammas* | *hamba* | *hammast* |
|  | *kallis* | *kalli* | *kallist* |
| Special forms | *käsi* | *käe* | *kätt* |
|  | *vesi* | *vee* | *vett* |
|  | *süda* | *südame* | *südant* |
| Lost consonant | *laps* | *lapse* | *last* |
|  | *uks* | *ukse* | *ust* |

Some words in *-as* with genitive *-sa* allow two forms: *armas, armsa, armast* or *armsat*.

## Partitive in a vowel (§ 204–207)

Most often the ending is the final vowel of the genitive, added to the nominative.

| Nominative | Genitive | Partitive |
|---|---|---|
| *kurk* | *kurgu* | *kurku* |
| *hind* | *hinna* | *hinda* |
| *leht* | *lehe* | *lehte* |
| *pank* | *panga* | *panka* |
| *sepp* | *sepa* | *seppa* |
| *mägi* | *mäe* | *mäge* |
| *sõber* | *sõbra* | *sõpra* |

Other patterns:

| Pattern | Examples (nominative, genitive, partitive) |
|---|---|
| Genitive and partitive look alike, but the partitive is said with overlong quantity | *linn, linna, linna · õun, õuna, õuna · tool, tooli, tooli* |
| All three forms alike | *kala, kala, kala · nina, nina, nina · kuju, kuju, kuju* |
| Weak genitive, strong partitive | *rada, raja, rada · pada, paja, pada · vägi, väe, väge* |
| Nominative in *-i*, genitive and partitive in *-e* | *suvi, suve, suve · nimi, nime, nime* |

## Agreement (§ 208)

An adjective agrees: *Otsin punast pliiatsit.* "I'm looking for a red pencil."

## Main uses (§ 209–214)

| Use | Example | English |
|---|---|---|
| After numbers from two up, fractions, *paar*, *mitu* | *neli autot* | four cars |
|  | *pool tundi* | half an hour |
|  | *paar eurot* | a couple of euros |
|  | *Mitu õde sul on?* | How many sisters do you have? |
| After quantity words | *vähe raha*, *rohkem aega* | little money, more time |
|  | *Klaas on vett täis.* | The glass is full of water. |
| Partial object (Lesson 28) | *Ma joon teed.* | I'm drinking tea. |
| Partial subject | *Kas piima on?* | Is there any milk? |
|  | *Hommikul sadas vihma.* | It rained in the morning. |
| Type or kind | *Mu auto on sinist värvi.* | My car is blue. |
|  | *Ta on keskmist kasvu.* | He is of medium height. |
| With some prepositions | *enne tööd*, *pärast kontserti* | before work, after the concert |
|  | *keset ööd*, *mööda jõge* | in the middle of the night, along the river |
|  | *vastu tuult*, *alla jõge* | against the wind, down the river |

A partial subject contrasts with a whole one: *Kas piima on?* asks about any amount, while *Piim on külmkapis.* means "The milk is in the fridge."

## Useful phrases

| Estonian | English |
|---|---|
| *Palju õnne!* | Congratulations! |
| *Head päeva!* | Have a nice day! |
| *Üks tass teed, palun.* | A cup of tea, please. |
| *Pool kilo juustu, palun.* | Half a kilo of cheese, please. |
| *Kui palju see maksab?* | How much does this cost? |
| *Mul pole aega.* | I have no time. |
