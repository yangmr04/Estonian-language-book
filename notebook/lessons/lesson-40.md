# Lesson 40: Adpositions, Case Government and Connectors

[Index](../README.md) · Book: p. 315 · § 398–408 · [← Previous](lesson-39.md)

## Key ideas

- Prepositions and postpositions each require a particular case.
- Many verbs and adjectives also require a particular case, so learn them together.
- *Kui* has several uses, and *kuna* can mean "since" or "while".
- This lesson's lists are selective. They are a practical starting point.

### With the elative

*Aknast välja* "out of the window", *mäest üles* "up the hill", *tunnelist läbi* "through the tunnel", *lapsest saadik* "since childhood", *sellest peale* "from then on".

## Verbs and adjectives that require a case (§ 403–405)

### Verbs

| Case or phrase | Verbs | Example |
|---|---|---|
| Partitive | *aitama, armastama, kartma, vajama, paluma, tänama, kadestama, segama* | *Ta kardab koera.* |
| Elative | *aru saama, sõltuma, unistama, loobuma, hoolima, osa võtma* | *Ma saan sellest aru.* |
| Illative | *armuma, suhtuma, puutuma* | *Ma armusin sellesse linna.* |
| Allative | *helistama, meeldima, vastama, andestama, järgnema, sobima* | *Helista emale!* |
| Ablative | *küsima, laenama* | *Ma küsin õpetajalt.* |
| Comitative | *harjuma, tegelema, abielluma, kohtuma, nõustuma* | *Ma olen külmaga harjunud.* |
| Translative | *pidama, muutuma, saama, nimetama* | *Ta sai arstiks.* |
| *kelle eest?* | *hoolitsema* | *Ta hoolitseb oma ema eest.* |
| *mille üle?* | *imestama, naerma* | *Mille üle sa naerad?* |
| *mille vastu?* | *huvi tundma* | *Ma tunnen huvi ajaloo vastu.* |

### Adjectives

| Case or phrase | Adjective | Example |
|---|---|---|
| Allative | kasulik "useful" | *See on tervisele kasulik.* |
| Allative + *eest* | tänulik "grateful" | *Olen sulle abi eest tänulik.* |
| Elative | huvitatud "interested", teadlik "aware", väsinud "tired" | *Ta on muusikast huvitatud.* |
| Illative | armunud "in love" | *Ta on naabrisse armunud.* |
| Inessive | kindel "sure" | *Ma olen selles kindel.* |
| Comitative | sarnane "similar" | *Poeg on isaga sarnane.* |
| *mille üle?* | uhke "proud" | *Ta on oma töö üle uhke.* |
| Allative or *kelle peale?* | pahane "annoyed" | *Ära ole minu peale pahane!* |

## Conjunctions (§ 406–407)

| Word | Meaning |
|---|---|
| *ja, ning* | and |
| *aga, kuid* | but |
| *või* | or |
| *et* | that |
| *sest* | because |
| *kuigi, ehkki* | although |
| *enne kui* | before |
| *niipea kui* | as soon as |
| *nii ... kui ka* | both ... and |
| *ei ... ega* | neither ... nor |
| *mitte ainult ... vaid ka* | not only ... but also |

Some need extra care:

| Word | Use | Example | English |
|---|---|---|---|
| *kas* | whether | *Ma ei tea, kas pood on lahti.* | I don't know whether the shop is open. |
| *kui* | when, if | *Kui on külm, pane müts pähe.* | If it's cold, put on a hat. |
| *kui* | than, as | *Mari on pikem kui Jaan.* | Mari is taller than Jaan. |
| *kuna* | since | *Kuna sadas vihma, jäime koju.* | Since it was raining, we stayed home. |
| *kuna* | while | *Isa küpsetas, kuna ema luges.* | Father baked while Mother read. |

Current practice writes most of these without periods.

| Abbreviation | Full form | Meaning |
|---|---|---|

| hr | *härra* | Mr. |

| nr | *number* | number |
| lk | *lehekülg* | page |

4. *___ sadas, läksime välja.*
5. *Ta ütles, ___ on väsinud.*
