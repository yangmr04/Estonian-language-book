# Lesson 5: Nominative Objects, Impersonal Sentences and Numbers 0–10

[Index](../README.md) · Book: p. 33 · § 24–26 · [← Previous](lesson-04.md) · [Next →](lesson-06.md)

## Key ideas

- In a command, an object that is affected as a whole stays in the nominative.
- Estonian has no dummy "it" or "there".
- In set phrases, even the verb can be left out.

## Objects in commands (§ 24)

A "total" object is one that the action covers completely. After a command, it takes the nominative, so it looks like the dictionary form. Lesson 28 returns to this topic.

| Command | English |
|---|---|
| *Osta leib!* | Buy the loaf of bread! |
| *Sule aken!* | Close the window! |
| *Kustuta tuli!* | Put out the light! |
| *Söö supp ära!* | Eat up the soup! |

Compare a partial object and a negative command, which use a different case (the partitive, taught later):

| Form | Example | English |
|---|---|---|
| Total, nominative | *Söö supp ära!* | Finish the soup! |
| Partial | *Söö suppi!* | Eat some soup! |
| Negative command | *Ära osta leiba!* | Don't buy bread! |

## Sentences without "it" or "there" (§ 25)

Where English needs a filler word, Estonian starts straight in with a third-person singular verb, or with another word before it.

| Estonian | English |
|---|---|
| *Sajab lund.* | It's snowing. |
| *Väljas on pime.* | It's dark outside. |
| *Täna on külm.* | It's cold today. |
| *Külmkapis on piim.* | There's milk in the fridge. |
| *Tundub, et ta on väsinud.* | It seems she is tired. |
| *On hea, et sa oled siin.* | It's good that you are here. |

In short comments, *on* can disappear as well:

| Estonian | English |
|---|---|
| *Kahju, et sa ei tule.* | Too bad you aren't coming. |
| *Tore, et sa tuled.* | Great that you're coming. |
| *Selge, et ta teab.* | Clearly he knows. |

## Numbers 0–10 (§ 26)

| | | | |
|---|---|---|---|
| 0 | *null* | 6 | *kuus* |
| 1 | *üks* | 7 | *seitse* |
| 2 | *kaks* | 8 | *kaheksa* |
| 3 | *kolm* | 9 | *üheksa* |
| 4 | *neli* | 10 | *kümme* |
| 5 | *viis* |  |  |

Watch out for the look-alikes *kaks* "2" and *kaheksa* "8", and *üks* "1" and *üheksa* "9".

## Useful phrases

| Estonian | English |
|---|---|
| *Mis ilm täna on?* | What's the weather like today? |
| *Üks hetk, palun.* | One moment, please. |
| *Palun üks kohv.* | One coffee, please. |
| *Kui palju see maksab?* | How much does this cost? |
| *Mis su telefoninumber on?* | What's your phone number? |
| *Aita mind!* | Help me! |

## Exercises

**A. Make a command using the verb and noun given.**

1. *ostma* (present stem *osta-*), *leib*
2. *sulgema* (present stem *sule-*), *aken*
3. *tooma* (present stem *too-*), *võti* "key"
4. *kustutama* (present stem *kustuta-*), *tuli*

**B. Write the numbers and answers as words.**

1. 3
2. 7
3. 9
4. *kaks pluss kolm on ___*
5. *kuus pluss neli on ___*
6. *viis pluss kolm on ___*

**C. Translate into Estonian.**

1. It's cold today.
2. It's snowing.
3. Too bad you aren't coming.
4. It's dark outside.
